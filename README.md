# IPL Data Analysis

## Project Overview
This project analyzes the IPL data from the inaugural seasons using Python, Pandas, Matplotlib, and Seaborn.
Cleaned and Imputed the missing values while ensuring integrity of the data 
Tracked performance of teams and players through visualisation and gained interesting subtle patterns from the data insights.

## Workflow
1. Data Loading & Cleaning
2. Exploratory Data Analysis
3. Data Visualization
4. Performance Insights

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
IPL Dataset sourced from Kaggle.
